# Clef classification evaluation — 2026-10-06

This sanitized summary covers three completed private batches for
`@cf/cloudflare/clef-flash`: the [12 routing fixtures](../evals/__datasets__/clef-routing.json)
and [five planning fixtures](../evals/__datasets__/clef-planning.json).
Each of the **17 unique synthetic cases was called once**. The smoke batch
contained the greeting case; the routing batch contained the other 11 original cases.

Each call asked three questions over shared context: model route, saved evidence
and research task. The runner made **17 classifier calls, zero generation calls,
and no retries**. All responses completed and validated; no errors or timeouts
were recorded. No classified request was executed and no research result was
generated by this evaluation.

## Interpretation and limits

Expected labels are provisional fixture judgments on a small synthetic
development set. They are not a representative benchmark, generation-model
quality results, scientific certainty, novelty validation or authorization to run
experiments. A matching evidence choice does not establish that a named record
exists. One quoted-instruction case is not a general prompt-injection guarantee.

The private manifests preserve hashes of the request builder and requests used
at execution. All three batches used the same builder, whose hash matches the
current local bundle. All evaluated prompts fit within 2,000 characters, so these
calls did not exercise long-input truncation or conversation recovery. Those
paths need separate code checks and acceptance.

The observed tradeoff is high agreement on this set with substantial abstention,
especially for evidence selection. Keep the thresholds and measure downstream
answer usefulness, real workspace latency and ambiguous follow-ups before
expanding what a decision can affect.

## Reproduction and privacy

The [bounded evaluation runner](../scripts/testing/CLEF-ROUTING-EVAL.md) imports
the shared request builder and uses the pinned official `cf` CLI through its
existing sign-in. Dry runs and fixture tests make no model calls. Live evaluation
requires explicit invocation and a new private output directory; failures stop
the batch without automatic replay.

This tracked summary contains aggregate metrics and public synthetic labels.
Raw prompts, private locations, account/request identifiers, credentials and
provider logs are excluded. Keep underlying receipts private. For current
configuration, see [Clef request planning](clef-routing.md).
