Kimi K3

kimi-coding · API key · deep reasoning
≤ 2
rank, n=3 in d=3
Proof-shaped reasoning. Asked to prove the covariance rank bound and say what it does to the 42-group error-geometry audit.
“Every per-group sample covariance matrix has rank at most min(3, 3−1) = 2, regardless of the data. … a monotonicity test on the sorted eigenvalues is tautological: sorting enforces λ₁ ≥ λ₂ ≥ λ₃ by construction, and rank ≤ 2 forces λ₃ = 0 by linear algebra, so the ‘test’ passes for every group no matter what the underlying MLIP errors look like. It carries zero statistical power.”
Proof sketch: S = (1/(n−1)) X Xᵀ; null(X Xᵀ) = null(Xᵀ) so rank(S) = rank(X) ≤ min(d, n); centering imposes X·1ₙ = 0, dropping one degree of freedom → rank ≤ min(d, n−1); sharp in generic position. Valid test proposed: n > d per group, or an estimable quantity (top-eigenvector direction, λ₁/λ₂ on n−1 d.o.f., permutation/bootstrap nulls) rather than a deterministic consequence of sorting and rank deficiency. This matches the manuscript's “21 n=3 groups rank-limited” panel.
